# 🍔 Loqma Food Delivery Platform

## 📌 Project Description
Loqma is a modern food ordering and delivery web interface designed to help users explore restaurants and order meals easily.

The project contains:
- Responsive navigation bar
- Hero section with search functionality
- Food categories section
- Featured meals cards
- Professional footer section

This project was created as a front-end practice project using basic web technologies.

---

## 🛠️ Technologies Used
- HTML5
- CSS3
